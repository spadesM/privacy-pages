Beş aşamalı, asenkron ve serverless orkestrasyon. Her aşama bir öncekinin ürettiği event ile tetiklenir.

Ingest

Full-length filmin low-res kopyası incoming/, CMS kaydı cms/ altına S3’e yüklenir.

STAGE 2

Trigger

STAGE 3

STAGE 5

Serve

02 · Modeller

MovieTag mimarisi: vision ana stream, audio ve text context

FiLM conditioning: context vector c, visual temsili boyut bazında scale (γ) ve shift (β) eder; “ne duyuluyor, ne konuşuluyor” bilgisi görüntüyü yeniden ağırlıklandırır.
Identity init: γ=1, β=0 ile başlar; training saf vision modelinden başlayıp audio/text etkisini kademeli öğrenir.
Multi-label output: label_selection.xlsx’teki N label + “No label” için bağımsız sigmoid; her class’ın kendi threshold’u var.

t*: precision ≥ 0.6 koşuluyla F1’i maksimize eden threshold (0.1–0.8 grid). Support < 5 ise τ = 0.5. Sonuç τ ∈ [0.44 , 0.59] — overfitting’i sınırlar.

03 · Filmden micro-genre’ye

Filmden label’a: 6 adımlı inference pipeline

Processing container’ında worker, MovieTag test_pipeline.py’yi subprocess olarak çalıştırır. Tüm model ağırlıkları image içinde; runtime’da download yok.

1

Stream seçimi

ffprobe ile en çok kanallı İngilizce audio ve İngilizce altyazı (SDH öncelikli) seçilir.

2

Segmentation

~300 sn hedef; silencedetect (−30 dB, ≥0.7 sn) ile en yakın sessizlikten kesilir.

3

Embedding extraction

CLIP: her 10. frame · CLAP: 10 sn window · text: segment altyazısı ya da CMS title + summary.

4

Segment prediction

Sigmoid olasılıklar class threshold’larıyla filtrelenir; “No label” elenir.

5

Film-level aggregation

score = segment frekansı × ortalama olasılık; score < 0.05 elenir.

6

Taxonomy mapping

Type = Genres → micro_genres; diğer tüm Type’lar → micro_tags.

Segmentlerden film label’ına: dominance score

Neden frekans × olasılık?

  • Frekans tek sahnelik label’ları bastırır; filmin geneline yayılan temaları öne çıkarır.
  • Ortalama olasılık modelin o segmentlerdeki confidence’ını taşır.
  • Label’lar score’a göre azalan sırada döner.

Production adapter ayarları

  • prediction_threshold: 0 → class-wise tuned threshold’lar
  • min-tag-score 0.05 → nadir label’lar elenir
  • ~300 sn segment → 2 saatlik filmde ~24 segment
  • Her iki liste de dolu olmalı; aksi halde publish yapılmaz

Feature flag ile kontrollü rollout

Reader Lambda, recommender’a sinyal sağlayan entegrasyon endpoint’i. EnableModelTags parametresi model sinyallerinin recommender’a açılışını yönetir.

Flag kapalı

EnableModelTags = "false"
{
  "content_id": "napoleon-full",
  "genre": "Drama"
}

Yalnızca CMS genre döner; OpenSearch’e istek atılmaz. Mevcut davranış korunur.

Flag açık

EnableModelTags = "true"
{
  "content_id": "napoleon-full",  "genre": "Drama",
  "micro_tags": ["suspense", "music", "death", "war", …],
  "micro_genres": ["action", "horror", "thriller"]
}

Active alias’tan doküman okunur; kayıtlar type’a göre ayrılır.

STEP 1

Flag kapalı deploy

İlk kurulum "false" ile; consumer’lar etkilenmez.

STEP 2

Publish’i doğrula

SageMaker Completed, DynamoDB COMPLETED, index’te doküman.

STEP 3

Aç ve redeploy

"true" → deploy.ps1; Reader label’ları döner.

ROLLBACK

Tek parametre

"false" + redeploy; veri korunur.

05 · Pipeline detayları

Security ve operasyon

Least privilege (IAM)

  • Processing role yalnızca staging/* okur, results/* yazar
  • Starter yalnızca JobPrefix* job’ları açar; PassRole sadece SageMaker’a
  • Reader: cms/* + OpenSearch GET

Encryption

  • S3 SSE-AES256 · SQS managed SSE
  • OpenSearch at-rest + node-to-node encryption
  • HTTPS zorunlu · TLS 1.2+

Secret-free

  • OpenSearch çağrıları Lambda role’üyle SigV4 imzalı
  • Config dosyalarında key/şifre yok
  • Model ağırlıkları image içinde; runtime download yok

Resilience

  • EventBridge ve Lambda: 2 retry, 1 sa max event age
  • Başarısız event’ler SQS DLQ’da 14 gün
  • Conditional write ile duplicate job engeli

Observability

  • CloudWatch Logs: Starter · Publisher · Reader · Processing
  • DynamoDB job state: RUNNING · COMPLETED · FAILED · STALE
  • SageMaker FailureReason kayıt altında

Cost control

  • Aynı video version’ı tekrar job açmaz (idempotent)
  • Processing compute yalnızca job süresince ücretlenir
  • GPU stack ayrı region’da (eu-west-1); CPU stack’ten izole
